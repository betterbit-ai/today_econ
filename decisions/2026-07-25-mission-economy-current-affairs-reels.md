# 경제·시사 릴스 매거진으로 프로젝트 방향 전환

## Decision

오늘경제를 매일 경제 뉴스 1개와 시사 뉴스 1개를 골라, 경제뉴스를
챙길 시간이 부족한 20~30대 직장인과 사회초년생 재테크 초보자에게
짧고 이해하기 쉬운 릴스로 전달하는 데일리 경제 매거진으로 운영한다.

## Context and constraints

기존 파이프라인은 하루 한 건의 카드뉴스에 설명과 자체 인사이트를
담았지만, 기사에 없는 의미를 강제로 만들 때 품질과 신뢰도가 떨어졌다.
개편 후에는 대중의 관심을 끄는 주제와 타이틀을 선택하되, 본문은 기사에
근거한 정확한 요약을 제공한다. 본문은 정확히 3문장, 문장당 최대 약
120자로 제한하며 기사에 명시된 전망이나 의미가 없을 때는 인사이트를
추가하지 않는다.

운영은 하루 2편 발행을 기본으로 하고, 별도 데이터베이스와 상시 유료
인프라 대신 GitHub에 선택·생성·발행 기록을 남기는 단순하고 추적 가능한
구조를 우선한다. OBMC의 운영 전략은 참고하지만 이름, 로고, 문구,
디자인은 독립적으로 만든다.

## Alternatives considered

- 하루 한 건의 상세 카드뉴스 유지: 더 많은 설명을 담을 수 있지만,
  발행 빈도와 짧은 소비 경험이라는 새 방향에 맞지 않아 채택하지 않았다.
- 모든 게시물에 자체 투자 인사이트 추가: 기사에 없는 추론과 반복적인
  조언을 만들 위험이 있어 채택하지 않았다.
- 별도 데이터베이스 도입: 현 성장 단계에서 운영 비용과 복잡성이
  커지므로 GitHub 기록으로 충족할 수 없는 요구가 생길 때까지 미룬다.
- OBMC의 브랜드 표현을 직접 복제: 빠르게 유사한 인상을 낼 수 있지만,
  독립적인 브랜드 정체성과 지속 가능성을 해치므로 채택하지 않았다.

## Revisit when

- 하루 2편 발행 기록의 양이나 동시성이 GitHub 파일 기반 운영의
  안정성과 처리 속도를 저해할 때
- 경제·시사 2개 분야 구성이 독자 성장이나 콘텐츠 품질을 지속적으로
  제한한다는 데이터가 쌓일 때
- 3문장·문장당 약 120자 형식이 기사 정확성이나 이해도를 반복적으로
  훼손할 때
- 채널의 핵심 독자층이 20~30대 직장인·사회초년생을 넘어 명확하게
  변화했을 때

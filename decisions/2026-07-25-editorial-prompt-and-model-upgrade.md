# 2026-07-25 Editorial Prompt and Model Upgrade

## Context
DIEM 릴스 발행 자동화 파이프라인에서 생성되는 커버 타이틀과 본문 내용의 품질 저하 문제가 발견되었습니다.
- 커버 타이틀이 시청자의 시선을 끄는 형태(Hook)가 아니라 단순 키워드 나열식("대통령 젠슨 24일 흐름정리")으로 작성됨.
- 본문에 기사 원문의 이미지/사진 묘사("오른쪽부터 ~", "건배하고 있다")나 언론사 이름("연합뉴스")이 필터링 없이 그대로 복붙되어 인스타그램 문맥에 맞지 않는 현상이 발생함.
- 뜬금없는 이모지가 생성되거나 문장 중간에 삽입됨.
- Groq의 모델 정책에 따라 기존 모델들(`llama-3.1-8b-instant`, `llama-3.3-70b-versatile`, `qwen/qwen3.6-27b`)이 Decommissioned 처리될 예정이거나 파싱 문제를 야기함.

## Decision
1. **메인 모델 교체**: Groq API의 최신 모델 정책에 맞춰 주력 생성 모델(`primary`)을 `openai/gpt-oss-120b`로 확정하고, `fallback` 모델을 `openai/gpt-oss-20b`로 교체하였습니다. (qwen 모델은 `<think>` 태그 출력으로 인해 JSON 파싱 에러를 유발하므로 제외)
2. **프롬프트 고도화 (`src/v2/editorial.js`)**: 
   - 이미지 묘사(예: 왼쪽부터, 건배하고 있다)와 언론사/기자 이름의 원천 배제 규칙 추가
   - 직관적인 훅(Hook) 형태의 2줄 타이틀(각 14자 이하) 강제 규칙 추가
   - 이모지를 본문(sentences)이 아닌 별도 `emojis: { first, third }` 객체로 자동 생성하도록 구조 강제화
   - 자연스러운 서술형 종결 어미(`~다`, `~요`) 강제

## Consequences
- AI가 생성한 느낌을 줄이고 에디터가 직접 쓴 듯한 자연스럽고 매끄러운 릴스 대본을 보장하게 되었습니다.
- 기사 원문의 불필요한 메타 정보(사진 설명, 언론사명)가 릴스 시청자에게 노출되는 것을 방지합니다.
- `qwen` 모델의 JSON 파싱 실패(`json_validate_failed`) 문제를 회피하고 안정성을 확보했습니다.

# 브랜드 영업보다 1개월 콘텐츠 품질 검증을 먼저 수행한다

## Decision

DIEM은 Gifts와 브랜드 아웃바운드를 당장의 성장 목표로 삼지 않는다.
4주 동안 핫뉴스 품질과 성과 측정을 안정화하고, 운영자 승인형 `DIEM 기초`
콘텐츠를 주 1편씩 총 4편 발행한 뒤에 브랜드 협업 준비 여부를 다시
판단한다.

첫 협업 후보는 도서, 경제교육, 커리어와 생산성 서비스 같은 비투자형
브랜드로 제한한다. 실험 기간에는 광고 안내 게시물, 공개 미디어킷과 직접
영업을 만들지 않는다.

## Context and constraints

- 조회수 사례는 있지만 최신 V2 게시물별 성과가 자동 축적되지 않아
  반복 가능한 성과를 증명할 수 없다.
- 운영자가 최근 콘텐츠의 제목, 본문과 사진 품질을 브랜드 포트폴리오로
  쓰기에 부족하다고 판단했다.
- 초기 계정에서 광고 안내를 전면에 내세우면 독자 가치보다 수익화 의도가
  먼저 보일 수 있다.
- Slack 인바운드 승인을 위한 상시 서버를 추가하지 않고 GitHub-first와
  무상 인프라 원칙을 유지해야 한다.

## Alternatives considered

- 팔로워 500명과 Instagram Gifts를 첫 목표로 삼기: 제작 비용 대비 예상
  수익이 작고 현재 콘텐츠 품질 문제를 해결하지 않는다.
- 즉시 비투자형 브랜드에 아웃바운드 제안하기: 낮은 품질의 현재 콘텐츠가
  그대로 포트폴리오가 될 위험이 있어 기각했다.
- Slack 인터랙티브 버튼으로 승인하기: 요청을 수신할 상시 서버가 필요해
  현재 인프라 원칙과 맞지 않는다.
- `DIEM 기초`를 자동 발행하기: 첫 4주 품질 검증 목적과 충돌하므로
  GitHub Action 수동 승인 방식을 선택했다.

## Revisit when

- 운영자 승인 `DIEM 기초` 4편과 각 콘텐츠의 7일 성과가 축적됐을 때
- 최신 V2 핫뉴스의 측정 누락이 해소되고 품질 실패 회귀 테스트가 안정화됐을 때
- 운영자가 4주 종료 리포트에서 `유지` 또는 `수정 후 재시험`을 선택할 때

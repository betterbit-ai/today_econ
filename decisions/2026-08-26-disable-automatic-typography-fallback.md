# 자동 뉴스에서는 기본 타이포그래피 폴백을 발행하지 않는다

## Decision

자동 뉴스의 이미지 경로는 `검수된 웹 이미지 → 주제별 프로젝트 생성 자산 →
후보 실패`로 닫는다. 생성 자산은 13개 시나리오에 2~3장씩 두고 기사별 안정적
셔플과 최근 7일 중복 금지를 함께 적용한다.

## Context

2026-08-25 원장에서 생성 자산이 선택된 두 건도 publisher가 로컬 경로를 버려
실제 표지에는 기본 아트가 보일 수 있었다. 같은 날 의료와 공공이슈는 매칭 생성
자산이 없어 타이포그래피로 발행됐다. 단일 생성 이미지도 최근 7일 재사용 금지
뒤 곧바로 소진된다.

## Rejected

- 기본 아트를 마지막 안전망으로 유지: 사용자가 반복해서 삭제한 저신뢰 결과를 계속 만든다.
- 생성 자산의 7일 중복 금지 완화: 다른 기사에 같은 배경이 반복되는 기존 문제를 되살린다.
- 런타임 이미지 생성 API: 무료·무인 운영에서 지연과 품질 변동을 통제하기 어렵다.

## Directive

새 시나리오는 사람·얼굴·문자·숫자·로고·국기 없이 2장 이상을 먼저 생성하고
manifest 해시·세로 규격 테스트를 추가한 뒤 매핑한다. 자산 소진은 발행 강행이
아니라 다음 후보 이동 사유다.

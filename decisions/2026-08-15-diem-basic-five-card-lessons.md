# DIEM Basic은 5장으로 완결되는 교육 Reel로 발행한다

## Decision

DIEM Basic 한 편을 질문 표지, 쉬운 정의, 작동·비교, 오해·주의, 한 줄
정리의 5장으로 제작한다. 장면은 3·4·5·4·3초 동안 노출하고 정적 페이드로
연결해 19초 Reel을 만든다. 핵심 학습은 영상 안에서 끝나야 하며, 3문장
캡션은 보충 설명으로만 사용한다.

교육 시리즈는 웜 아이보리 종이 배경, 네이비 본문, 코발트 핵심색, 민트
보조색을 사용한다. 날짜, Economy/Issue, 뉴스 사진과 사람 얼굴은 금지하고
흐름도·비교표·산식·체크리스트 같은 프로젝트 원본 도식으로 설명한다.

수업 카드와 캡션은 정확성을 유지한 자연스러운 `해요체`로 쓴다. 독자가
실제로 물을 법한 질문과 구체적인 동사를 사용하고, “먼저 봅니다”, “오해부터
바로잡습니다”, “기억하세요” 같은 편집자 진행 문구와 교과서식 명령은 쓰지
않는다. 문장을 고친 뒤에는 이름·숫자·조건·예외를 원래 `claims`와 다시
대조한다.

Git 패키지는 카드 5장, 첫 장과 동일한 표지, 최종 Reel과 모든 파일의
SHA-256을 보관한다. Action은 이 완성 패키지와 검토 기한을 검증해 발행만
하며 렌더링·원고 변경은 계속 금지한다.

## Context and constraints

- 기존 1장 7초 Reel은 뉴스 표지와 시각적으로 비슷해 교육 시리즈인지 즉시
  알기 어려웠다.
- 설명이 캡션에만 있으면 Reel을 본 사람이 핵심 구조를 배우거나 저장할
  이유가 약하다.
- 교육 콘텐츠는 인물·웹 사진보다 사실과 직접 연결된 도식이 신뢰와 권리
  측면에서 안전하다.
- 별도 DB와 상시 유료 인프라 없이 Git을 완성 미디어의 원본으로 유지한다.
- Instagram 자동 발행 시점에 동적 렌더링을 하면 사전 시각 검수와 해시
  무결성이 무의미해진다.

## Alternatives considered

- 1장 표지와 긴 캡션 유지: 제작은 단순하지만 사용자가 지적한 뉴스·교육
  구분과 영상 내 학습 완결성을 해결하지 못해 기각했다.
- 내레이션 중심 영상: 설명량은 늘지만 음성 제작·발음·자막 동기화와 검수
  표면이 첫 4편 실험에 과도해 기각했다.
- 뉴스 디자인에서 색상만 변경: 시리즈 구분은 조금 나아지지만 정보가 여전히
  표지 한 장에 머물러 기각했다.
- 사진 기반 카드 5장: 주제별 이미지 권리·인물 오인·반복 배경 문제를 다시
  만들 수 있어 기각했다.

## Revisit when

- 첫 4편의 7일 저장률, 공유율, 평균 시청 시간과 팔로우 전환이 모두 모일 때
- 19초 완주율이 반복적으로 낮고 더 짧은 장면 수가 낫다는 비교 근거가 생길 때
- 음성 설명이 접근성·이해도를 유의미하게 높인다는 제작 실험을 승인할 때
- 카드 미디어가 Git 저장소 크기나 발행 대기 시간을 운영상 저해할 때
- 독자 반응과 실제 작성 표본에서 현재 `해요체`보다 더 적합한 일관된 브랜드
  목소리가 확인될 때

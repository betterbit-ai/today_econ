# 로컬 유사도와 권리 확인 미디어를 V2 생성 의존성으로 사용

## Decision

최근 7일 주제 중복은 로컬 다국어 문장 임베딩을 사용해 판정한다.
`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`를
기본 모델로 고정하고, 코사인 유사도 0.78 이상은 중복, 0.68~0.78은
핵심 대상과 사건이 모두 겹칠 때 중복으로 처리한다. 모델 실패 시
키워드·개체 기반 결정적 판정으로 폴백한다.

표지 이미지는 Pexels, Unsplash, 조건이 확인된 Wikimedia Commons와
명시적 재사용 허가가 있는 공식 보도 자료에서만 자동 선정한다. 적합한
이미지가 없으면 검수된 분야 이미지, 마지막에는 사진 없는 DIEM
타이포그래피 표지로 폴백한다.

BGM은 외부 유행 음원 대신 직접 제작한 경제 3곡·시사 3곡을 사용한다.
직전 곡을 피하고 최근 사용 횟수와 주제 분위기로 순환하며, 민감한
주제나 합성 실패에는 무음으로 발행한다.

제목과 본문 생성은 Groq 무료 티어의 `openai/gpt-oss-120b`를 기본,
`qwen/qwen3.6-27b`를 폴백으로 사용한다. 모든 호출 실패 시 검증된 기사
문장에서 규칙 기반 결과를 만들며 유료 호출로 자동 전환하지 않는다.

## Context and constraints

기사 제목만 비교하면 같은 사건의 표현이 달라졌을 때 중복을 놓치고,
제목·긴 요약·모든 개체를 그대로 합치면 서로 다른 세부 보도까지 과도하게
가까워질 수 있다. 따라서 분야·핵심 대상·사건·주요 개체로 짧은 주제
서명을 만들고 회색 구간을 별도로 판정한다.

AI 생성 이미지는 과거 품질이 만족스럽지 않았고, 일반 웹 검색 이미지는
저작권을 확인하기 어렵다. 권리 확인 출처와 무사진 폴백을 함께 두어
이미지 품질이 발행 안정성보다 앞서지 않게 한다.

기존 Groq의 `llama-3.3-70b-versatile`과
`llama-3.1-8b-instant`는 2026년 8월 16일 무료·개발자 티어 종료가
예정돼 있어 V2에서 교체한다. 종료 일정과 권장 대체 모델은
[Groq 공식 폐기 일정](https://console.groq.com/docs/deprecations)을
기준으로 한다.

## Alternatives considered

- 제목만 문자열 비교: 표현이 다른 동일 사건을 놓쳐 채택하지 않았다.
- 0.8 단일 임계값: 유사 후속 기사와 동일 사건 경계에서 융통성이 없어
  0.78 자동·0.68 회색 구간을 채택했다.
- 외부 벡터 DB: 현재 7일·하루 2건 규모에서 불필요해 채택하지 않았다.
- 일반 이미지 검색 결과 사용: 재사용 권리를 보장할 수 없어 채택하지
  않았다.
- AI 배경 이미지 생성: 과거 품질 문제와 결과 일관성 때문에 초기
  V2에서는 채택하지 않았다.
- Instagram 유행 음원 자동 선택: API와 상업적 사용 권리가 불확실해
  채택하지 않았다.
- 기존 Groq 모델 유지: 예정된 종료로 곧 실패하므로 채택하지 않았다.

## Revisit when

- 라벨 기사 쌍 회귀 결과에서 중복 오탐·미탐이 허용 범위를 넘을 때
- GitHub Actions의 모델 다운로드 시간이나 캐시 용량이 운영을 방해할 때
- 권리 확인 이미지 공급처의 API·약관이 바뀔 때
- 오리지널 6곡의 반복 피로도가 실제 독자 반응에 나타날 때
- Groq 무료 티어, 모델 가용성 또는 한국어 생성 품질이 달라질 때

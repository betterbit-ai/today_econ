# DIEM 브랜드와 짧은 편집 형식을 하나의 계약으로 사용

## Decision

오늘경제의 기존 계정을 `DIEM — Daily Issue & Economy Magazine`으로
리브랜딩한다. 우선 사용자 이름은 `@diem.magazine`, 폴백은
`@diem_magazine`으로 하며, 기존 게시물은 유지하고 전환 공지는 별도로
발행하지 않는다.

모든 V2 릴스는 하나의 DIEM 디자인으로 만든 7초 단일 표지 영상이다.
표지는 날짜·분야와 14자 이하의 2줄 타이틀만 담고 첫 줄은 블루,
둘째 줄은 화이트로 표시한다. 본문은 정확히 3문장, 문장당 120
grapheme 이하로 작성하며 첫째·셋째 문장 끝에만 문맥에 맞는 이모지
하나를 둔다.

## Context and constraints

핵심 독자는 긴 카드뉴스보다 짧고 빠르게 이해되는 경제·시사 요약을
필요로 한다. 기존의 여러 테마와 다중 카드 구조는 매일 두 편을 일관된
브랜드로 발행하려는 V2 방향에 비해 복잡하다.

팔로워가 200명 미만인 현재 단계에서는 별도 전환 공지가 주는 이익보다
새 피드의 일관성을 해치는 비용이 크다. 기사에 없는 생활 영향이나 투자
인사이트를 강제로 생성하지 않고, 기사에 명시된 배경·전망이 있을 때만
셋째 문장에 재사용한다.

## Alternatives considered

- 새 계정 개설: 기존 팔로워와 Instagram API 연결을 잃으므로 채택하지
  않았다.
- 전환 공지 게시물 고정: 현재 팔로워 규모에서 별도 설명의 가치가 낮아
  채택하지 않았다.
- Obsidian·Ivory·Cyber 테마 유지: 주제별 변주는 가능하지만 DIEM의
  통일된 인상을 약화하고 제작 복잡성을 늘려 채택하지 않았다.
- 영상 안에 본문 3문장 표시: 7초 안에 읽기 어렵고 단일 표지 전략과
  충돌하므로 채택하지 않았다.
- 매번 “내 돈과 생활에 미치는 영향” 생성: 근거 없는 인사이트를 만들
  위험이 있어 채택하지 않았다.

## Revisit when

- 독자 조사에서 단일 표지만으로 핵심 이해가 어렵다는 결과가 반복될 때
- 3문장·120자 제한이 정확한 전달을 지속적으로 훼손할 때
- 계정 성장 후 브랜드 전환 설명이나 과거 게시물 정리가 실제로 필요할 때
- 경제·시사 레이블만으로 분야 구분이 충분하지 않다는 시각 검증이 쌓일 때

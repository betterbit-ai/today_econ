# 분야별 두 편을 허용하고 검수된 생성 배경을 사진 폴백으로 사용한다

## Decision

6시간 폴링은 유지하며 일반 자동 발행 상한은 KST 날짜별 Economy 2편과 Issue
2편으로 조정한다. 품질을 통과한 뉴스가 없으면 네 편을 채우지 않는다.

웹 이미지 공급원 또는 Vision 검수가 실패했을 때 바로 반복적인 타이포그래피로
가지 않고, 과거 폴백에서 반복된 8개 주제에 맞춘 프로젝트 소유 생성 배경을
사용한다. 생성 배경은 실제 사건 현장이나 특정 인물을 묘사하지 않으며 7일
중복 금지를 동일하게 적용한다.

## Context

전체 원장에는 타이포그래피 폴백 41건이 있었다. 오래된 저품질 기사와 DIEM
Basic을 제외하면 반복 주제는 주거, 노동, 법·정책, 대중교통, 재난·기후,
안보·외교, 세금·금융, 반도체·산업으로 수렴했다. 2026-08-24에는 Groq Vision
요청이 무료 TPM 한도를 651토큰 초과해 주거 기사까지 타이포그래피로 닫혔다.

## Rejected

- 과거 41건마다 전용 이미지 생성: 현재는 발행 금지될 과거 기사까지 자산화한다.
- 생성 이미지를 실시간 API로 만들기: 비용·지연·품질 변동과 권리 추적이 커진다.
- 최근 중복을 무시하고 같은 생성 배경 반복: 기존 신뢰 문제를 반복한다.

## Directive

생성 자산을 실제 보도사진처럼 설명하지 않는다. 새 자산은 사람·문자·국기·로고
검수와 manifest 해시를 갖춘 뒤에만 추가한다.

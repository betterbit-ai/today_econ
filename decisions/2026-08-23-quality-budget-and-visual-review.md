# 폴링 빈도와 발행 예산을 분리하고 실제 이미지를 최종 검수한다

## Decision

Economy와 Issue의 6시간 폴링은 유지하지만 일반 자동 발행은 KST 날짜별
카테고리당 한 편으로 제한한다. 인기·신선도 임계값으로 발행량을 조절하지 않고
Git 원장에서 이미 발행된 횟수를 세어 예산을 집행한다.

이미지 선택은 서로 다른 검색 의도를 한 후보 풀에서 비교하지 않는다. 우선순위가
높은 검색 의도 안에서 shortlist를 만들고 실제 이미지 검수가 기사 사건, 국가,
정치 상징, 무관 인물을 확인한 뒤에만 웹 이미지를 사용한다. 검수 기능이 없거나
실패하면 프로젝트 원본 이미지로 닫는다.

## Context

2026-08-17~22에는 35편이 발행됐고 마지막 날 8편까지 늘었다. 타이포그래피
폴백 비율은 낮아졌지만 정책대출에 주식 차트, 공깃밥에 코스피 차트, 이란 기사에
청와대가 선택됐다. 메타데이터와 자기 검색어의 일치도는 실제 기사 문맥을
보장하지 못한다.

## Rejected

- 예약 실행 자체를 하루 두 번으로 축소: 시간 민감 후보를 관측할 기회가 줄어든다.
- 여러 검색어 후보를 한 번에 점수화: 서로 다른 의도의 자기일치 점수는 비교할 수 없다.
- vision 장애 시 메타데이터 1위 발행: 무관 이미지가 신뢰를 해치는 기존 사고를 반복한다.

## Revisit when

- 7일간 품질 사고가 0건이고 Control/Growth 실험을 활성화할 때
- 카테고리당 1편이 중요한 긴급 뉴스를 반복적으로 놓칠 때
- vision 모델 비용 또는 가용성이 0원 운영 원칙과 맞지 않을 때

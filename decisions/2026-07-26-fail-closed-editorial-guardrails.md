# DIEM 발행 가드레일은 불확실할 때 실패로 닫는다

## Decision

DIEM V2의 자동 발행은 모델 출력이나 deterministic fallback이 제목·본문
계약을 만족하지 못하면 `retry_pending` 또는 `no_publish`로 멈춘다.
빈말 제목, 원문 사진 설명, 언론사 저작권 표기, 120자를 넘는 장문 문장은
발행 가능한 에디토리얼 산출물로 보지 않는다.

AI·인공지능 키워드는 더 이상 단독 경제 신호가 아니다. 투자, 실적, 상장,
반도체, 시장, 산업 같은 경제 맥락이 함께 있을 때만 경제 후보로 인정하고,
개인정보·정보인권·기본권·특별법·동의 없는 원본 활용이 핵심이면 시사로
분류한다. 본문을 가져온 뒤에는 제목 기반 1차 분류를 다시 검증한다.

## Context and constraints

2026-07-26 발행에서 개인정보 원본 활용 논란 기사가 제목만 보고 경제로
분류되었고, 모델 제목 후보가 모두 검증에 실패하자 deterministic fallback이
`얼굴 목소리 / 흐름정리`라는 빈 제목과 사진 캡션·저작권 표기가 섞인 본문을
생성했다. 이는 매거진 신뢰를 직접 훼손하는 품질 사고다.

활성 스펙은 게시글 문장을 정확히 3문장으로 구성하고 문장당 120자 내외의
간결한 요약을 요구한다. 따라서 이전의 relaxed text limit 결정은 발행 실패를
줄이는 데는 도움이 되었지만, V2 운영 품질 기준으로는 너무 느슨하다.

## Alternatives considered

- 모델 프롬프트만 강화: 모델이 정상 응답할 때는 효과가 있지만, 모델 실패
  또는 무료 한도 장애 시 fallback이 같은 사고를 반복할 수 있어 충분하지 않다.
- fallback 제목을 더 다양한 템플릿으로 확장: 발행 지속성은 좋아지지만,
  기사 사건어를 못 잡는 상황에서 그럴듯한 빈 제목을 만들 위험이 커져
  채택하지 않았다.
- 모든 AI 관련 기사를 시사로 고정: 개인정보 사고는 막지만, AI 반도체 투자,
  상장, 실적 같은 실제 경제 기사를 놓칠 수 있어 채택하지 않았다.

## Revisit when

- 발행 전 사람 승인 큐가 생겨 자동 발행 실패 대신 수동 편집으로 넘길 수 있을 때
- 더 안정적인 유료 모델 또는 별도 검수 모델을 사용해 fallback 의존도가 낮아질 때
- DIEM이 긴 해설형 포맷으로 다시 전환되어 120자 캡션 계약이 바뀔 때

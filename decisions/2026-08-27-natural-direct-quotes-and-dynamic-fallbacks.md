# 간접명령형을 자연스러운 직접화법으로 고치고 사건 에너지에 맞는 배경을 고른다

## Decision

기사 인용문의 `오라 그래·하라 그래`를 표지 글자 수에 맞춰 그대로 자르지 않는다.
발언 대상의 전체 이름과 사건 맥락을 news frame에 고정한 뒤, 뜻을 바꾸지 않는
자연스러운 직접화법으로 제목을 교정한다.

생성 배경에는 calm/dynamic 에너지 구분을 두고, 파행·충돌·급등락·재난처럼
움직임이 핵심인 기사에는 dynamic 변형을 먼저 사용한다. 웹 이미지가 안전하게
통과하면 계속 웹 이미지를 우선하고, 생성 배경은 검수 실패 뒤의 안전망이다.

## Context

국군사관학교 공청회 기사에서 frame이 `규백이 오라 / 감소`로 잘못 구성돼
`규백이 오라 / 공청회 난무`가 발행됐다. 이미지도 `국군·국방부` 키워드 때문에
정적인 외교 회의실로 내려가 실제 사건의 파행성과 맞지 않았다.

## Rejected

- 원문 인용을 글자 수만 맞춰 유지: 전체 이름과 한국어 문장 맥락이 사라진다.
- 모든 기사에 역동 이미지 사용: 정례 정책·생활금융 기사까지 선정적으로 보인다.
- 인물 사진으로 공청회 갈등 표현: 초상·신원·권리 리스크가 커진다.

## Directive

직접화법 교정은 의미와 발언 대상을 바꾸면 안 된다. dynamic 이미지는 기사에
실제 움직임·충돌·급변 신호가 있을 때만 우선하고 최근 7일 중복 금지를 지킨다.

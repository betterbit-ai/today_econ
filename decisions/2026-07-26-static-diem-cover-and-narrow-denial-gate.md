# 정적 표지와 좁은 공식 부인 판정을 기본으로 사용

## Decision

DIEM V2 릴스는 합성된 표지 PNG 전체에 줌·팬을 적용하지 않고 정적
표지를 기본으로 사용하며, 공식 부인 상태는 부처·공식기관의 보도 반박
문맥이 분명한 경우에만 적용한다.

## Context and constraints

실제 Instagram 발행 결과에서 표지 PNG 전체에 `zoompan`을 적용하자
배경뿐 아니라 제목 텍스트까지 매 프레임 리샘플링되어 파란색·흰색 굵은
글자가 흔들려 보였다. DIEM의 현재 포맷은 영상적 움직임보다 한눈에
읽히는 제목과 신뢰감이 중요하다.

또한 공식 부인 게이트는 보건복지부의 해명자료처럼 기사 핵심이
"보도된 내용은 확정된 바 없다"인 경우를 막기 위해 도입되었다. 하지만
일반 경제 기사 안의 보조 문구나 시장 설명에 "확정된 바 없다"가 들어간
경우까지 공식 부인으로 분류하면, 제목에 "확정 아님" 같은 기계적인
표현이 강제로 남아 매거진 품질을 해친다.

## Alternatives considered

- 표지 전체 미세 줌 유지: 배경에 움직임은 생기지만 텍스트 품질이
  흔들리는 문제가 반복되어 채택하지 않았다.
- 배경 사진과 텍스트를 분리한 2-layer 영상 구성: 장기적으로는 가장
  자연스럽지만 현재 렌더링 구조보다 변경 범위가 커서 다음 개선으로
  미룬다.
- 모든 "확정 아님" 문구를 공식 부인으로 유지: 실제 공식 반박 기사는
  안전하게 막지만 정상 경제 기사까지 부정 상태로 오염시켜 채택하지
  않았다.

## Revisit when

- 배경 사진과 텍스트 레이어를 분리해 배경만 움직이는 렌더러를 도입할 때
- 공식자료/해명자료 URL을 별도 근거로 수집해 주장 상태를 더 정확히
  판정할 수 있을 때

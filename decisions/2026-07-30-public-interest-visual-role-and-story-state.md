# 공익성·방향성·시각 역할과 Story를 결정적 발행 계약으로 관리

## Decision

DIEM V2는 다음 네 항목을 프롬프트 권고가 아니라 코드로 검증하는 발행
계약으로 관리한다.

1. 해외 개인의 기이한 사건과 반응 중심 단신은 의료·교육 같은 분야 단어가
   있어도 법·정책·제도 또는 다수의 생활에 미치는 영향이 없으면 시사 후보에서
   탈락시킨다.
2. 선두·추격, 흑자·적자 전환처럼 방향이 핵심인 기사는 뉴스 프레임에 주체와
   현재 상태를 저장하고, 이를 뒤집거나 주체가 모호한 제목을 탈락시킨다.
3. 사람 사진은 주제 단어뿐 아니라 인물의 역할·연령·사건 속 지위가 맞아야
   한다. 동일성과 권리를 확인할 수 없거나 역할이 충돌하면 사진을 억지로
   쓰지 않고 분야별 DIEM 타이포그래피 표지로 폴백한다.
4. Instagram Story는 Reel 실패 시 대체 형식이 아니라 Reel 성공 뒤 같은
   공개 영상 URL을 쓰는 독립 배포 단계다. Reel, Story, 댓글은 각각 상태와
   시도 횟수를 가지며 Story 실패는 성공한 Reel을 되돌리거나 재게시하지 않는다.

국내 언론사의 시간대 없는 게시 시각은 Asia/Seoul로 해석하고, 사람의 병원
이송에 등장하는 일반적인 `긴급` 표현은 긴급 뉴스 보너스 근거로 쓰지 않는다.

## Context and constraints

2026-07-30 실제 발행에서 태국 학생의 분장 관련 병원 이송 단신이 `의료`,
`학생`, `긴급` 단어 때문에 높은 공익성과 긴급성을 가진 시사 뉴스로 오판됐다.
게시 시각 `YYYY-MM-DD HH:mm:ss`도 GitHub Actions의 UTC로 해석돼 실제보다 약
9시간 최신 기사처럼 계산됐다. 선택 사진은 `healthcare`라는 넓은 의미만 맞는
성인 의료인 사진이라 기사 속 학생·환자와 전혀 다른 역할을 보여줬다.

같은 날 경제 발행에서는 중국이 배터리·조선에서 이미 앞선다는 원문을
`중국 추격`으로 축약해 경쟁 방향을 거꾸로 읽히게 했다. 또한 워크플로가
`PUBLISH_INSTAGRAM_STORY=false`를 강제해, 기존 Story 배포 결정이 실제 운영에서
비활성화돼 있었다.

프로젝트는 무료 GitHub Actions와 Git 원장을 사용하므로 유료 비전 모델이나
별도 작업 큐를 추가하지 않는다. 이미지 공급자 메타데이터와 기사에서 추출한
시각 역할을 결정적으로 비교하고, 확신이 없으면 무사진 표지를 택한다.

## Alternatives considered

- LLM에게 공익성과 사진을 다시 질문: 무료 호출 한도와 모델 편차가 있고
  동일한 실패를 결정적으로 막지 못해 주 게이트로 채택하지 않았다.
- 의료·교육 키워드를 시사에서 전부 제외: 중요한 보건·교육 정책까지 잃으므로
  공익 근거가 없는 개인 단신만 탈락시키는 방식을 택했다.
- Story 실패 시 같은 실행 안에서 세 번 즉시 재시도: 외부 API 장애 때 실행
  시간을 소모하고 결과가 원장에 남지 않아, 실행당 한 번씩 최대 세 실행에
  걸쳐 복구하는 방식을 택했다.
- 부적합해도 비슷한 업종 사진 사용: 시각적 허위 인상을 만들 위험이
  무사진 표지보다 커서 채택하지 않았다.

## Revisit when

- 권리와 인물 동일성을 제공하는 신뢰 가능한 뉴스 사진 공급자를 확보할 때
- Meta가 Story 게시 계약이나 Business 계정 제한을 변경할 때
- 무사진 표지 비중이 높아져 검수된 로컬 이미지 풀을 운영할 필요가 생길 때

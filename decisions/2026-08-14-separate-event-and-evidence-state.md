# 의약품 안전 기사의 사건 상태와 근거 상태를 분리한다

## Decision

공식 당국이 복용 중단, 임신 회피, 피임 보완 같은 안전 지침을
발표한 기사는 해당 발표 사실을 `decided` 사건으로 다룬다. 임신 중
안전성이나 인과관계 근거가 충분하지 않은 경우는 별도
`evidenceState: limited`로 기록한다. 근거의 한계를 공식 권고
전체의 `미확정`으로 표지에 표현하지 않는다.

## Context and constraints

마운자로 기사에서 MHRA의 임신 회피·사전 중단 지침은 이미
발표됐지만, 자동 프레임이 본문의 `가능성`을 기사 전체의
미확정 상태로 해석했다. 그 결과 `마운자로 임신 위험 / 미확정`이라는
표지가 공식 복용 주의와 의학적 근거 제한을 둘 다 왜곡했다.

건강 콘텐츠는 길이보다 의미 범위가 중요하므로, 프롬프트만으로
완화하지 않고 코드 가드에서 두 상태를 분리한다.

## Alternatives considered

- 모든 `가능성`을 미확정으로 표시: 기사 속 서로 다른 주장에
  있는 불확실성을 뒤섮어 신뢰를 떨어뜨리므로 기각했다.
- 의약품 안전 기사 전체를 자동 탈락: 독자가 알아야 할 공식 안전
  지침마저 놓치므로 기각했다.
- 프롬프트만 수정: 동일한 의미 범위 오류가 다시 통과할 수 있어
  결정적 가드와 함께 적용한다.

## Revisit when

- 국내·해외 의약품 안전 기사 표본이 쌓여 일반화된 의료 주장
  택소노미가 필요할 때
- 권고 주체·대상·조건을 구조화한 공식 자료로 교차 검증할 수
  있게 될 때

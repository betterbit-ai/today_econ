# 편집·디자인 템플릿

## 한 편의 정보 구조

| 요소 | 역할 | 금지 |
| --- | --- | --- |
| 질문 | 초보자가 실제로 저장할 질문 | 당일 기사 제목 재활용 |
| 제목 1줄 | 대상을 명명 | 생소한 약어만 단독 사용 |
| 제목 2줄 | 차이·작동·영향을 명명 | `정리`, `완벽 가이드` 같은 빈 문구 |
| 문장 1 | 가장 쉬운 정의 | 광고성 장점 나열 |
| 문장 2 | 작동 방식·핵심 구분 | 원문 복사, 여러 문장 합치기 |
| 문장 3 | 오해·위험·재확인 | 투자 권유, 과장된 결론 |

3문장 본문은 영상의 보충 설명이다. 핵심 학습은 다음 5장 안에서 완결한다.

| 장면 | 길이 | 역할 | 권장 시각 문법 |
| --- | ---: | --- | --- |
| 01 질문 표지 | 3초 | 초보자가 실제로 묻는 질문 | 질문 + BASIC 노트 모티프 |
| 02 쉬운 정의 | 4초 | 대상을 쉬운 말로 정의 | 3단계 흐름도 |
| 03 작동·비교 | 5초 | 구조, 산식, 숫자 차이 | 비교표 또는 산식 |
| 04 오해·주의 | 4초 | 틀리기 쉬운 결론과 위험 | 체크리스트 또는 시차 |
| 05 한 줄 정리 | 3초 | 다시 볼 핵심 문장 | 요약 도식 + 저장 표시 |

표지 외 모든 장면은 하나 이상의 `claimIds`를 가져야 한다. 요약 장면도
앞에서 검증한 주장을 재조합할 뿐 새 사실을 추가하지 않는다.

## 시각 시스템

- 캔버스: 1080×1920, 웜 아이보리 `#F5F0E6` 종이 배경.
- 식별자: 모든 장에 `DIEM BASIC`, `경제기초 NN`, `현재 장 / 05`를 표시한다.
- 색상: 네이비 `#111827`, 코발트 `#315EFB`, 민트 `#24C68B`; 주의 장면만
  코랄 `#E85D4A`를 제한적으로 쓴다.
- 날짜, Economy/Issue, 기사 사진, 사람 얼굴은 넣지 않는다.
- 배경 장식보다 흐름도·비교표·산식·체크리스트가 실제 내용을 설명해야 한다.
- 뉴스 표지의 어두운 사진+하단 제목 구성을 재사용하지 않는다.
- 영상은 줌·흔들림 없이 5장의 정적 페이드만 사용한다.

## 자료 기록

`brief.md`에는 학습 질문, 한 문장 목표, 막아야 할 오해, 출처 우선순위,
디자인 의도, 재검토 조건을 남긴다. `content.json`은 기계가 검증하는 최종
원본이며 `brief.md`와 내용이 충돌하면 `content.json`을 수정하고 다시 빌드한다.

# DIEM Opus 운영 전환과 제작 정합성 개선

## 최종 모델 결정

새 뉴스 원고는 Claude Code 구독의 `claude-opus-5-5`로 고정한다. 공식 CLI 2.1.302, 기존 OAuth Secret, 도구·MCP·세션 저장 차단, 실제 응답 모델 ID 검증을 사용한다. 프로세스당 원고 요청은 최대 12회이며 자동 유료 API 또는 Groq 대체 호출을 하지 않는다. Groq는 이미지 Vision 검수에 계속 사용한다.

고정 기사 10건에서 Opus 자동 통과는 7건, Sonnet은 10건이었다. 다만 Opus가 통과한 최종 7건에는 명확한 사실·귀속 오류가 발견되지 않았고 Sonnet에는 정치적 귀속을 추가한 사례가 있었다. 이 작은 표본과 기존 자동 도입 기준 8/10 미달을 숨기지 않으며, 사용자의 최종 전환 요청에 따라 사실 정확성을 우선하는 새 운영 결정을 기록했다. 향후 실제 발행·쿼터 증거로 재평가한다.

## 어긋남의 원인과 수정

- 모델이 만든 imageKeyword가 최종 원고 조립 과정에서 빠졌다. 이제 최종 원고와 연결된 검색어를 보존한다.
- 넓은 주제 태그만으로 정치 발언에 법봉 그림을 배정할 수 있었다. 사건·주체·최종 제목·본문을 이미지 검수에 함께 제공한다.
- 생성 자산과 다운로드 실패 후 폴백이 실제 픽셀 검수를 우회했다. 생성 후보는 최대 두 쌍을 실제 이미지로 검수하고, 부적합하면 선택하지 않는다.
- 표지 합성 후 이미지와 문구의 일치를 확인하지 않았다. 최종 렌더 표지를 다시 검수하고, 원문 로컬 해시·원고·표지·완성 영상 해시를 연결한다. 발행 직전에 실제 파일 및 저장 Release의 해시를 재확인한다.
- 음악은 원문의 부수적 키워드와 긍정 단어를 우선해 감성적·경쾌한 곡을 붙일 수 있었다. 최종 제목·본문에서 분위기를 정하고 부정·민감 사안을 우선하며, 정식 라이선스와 곡명 정보가 있는 보수적인 뉴스 풀로 제한한다. 맞는 곡이 없으면 무음으로 처리한다.

## 데이터 및 검수 경계

Groq에는 기존 공개 기사 제목·최대 600자 요약 계약과 선택/합성 이미지로 검수한다. 원문 전문은 Groq로 새로 전송하지 않으며 로컬 해시 계산에만 사용한다. 실제 오디오를 AI가 청취·평가하는 기능은 구현하지 않았다. 음악 검수 증거는 분위기 규칙과 트랙 메타데이터이며 실제 사람의 청취와 구분한다.

기존 Basic의 사전 제작·승인·파일 검증 계약은 유지한다. 자동 발행 시각·분야별 하루 1편·flash 6초·explain 비활성화를 유지한다. 과거 원장과 게시물은 소급 변경하지 않는다. 적합한 사진/원고가 없는 후보는 건너뛴다.

## 실제 제작에서 추가 확인한 원인

첫 미리보기 39046422807은 3건 모두 이미지 단계에서 차단됐다. 증거를 추가한 진단 39046988286에서 API 오류와 의미상 거절을 구분했다. 주택 자산에는 실제 모델하우스의 군중/주소가 없다는 이유로 거절했고, 정치 발언과 국정감사 문건 기사에는 기존 법봉 자산이 부적합했다. 설명용 일러스트에는 정확한 현장 복제가 필요 없다는 기준을 명시하되, 단순한 넓은 주제 일치나 다른 사건을 암시하는 그림은 계속 금지한다.

새 정부 브리핑·재심 문서 검토 자산 2개를 내장 imagegen으로 제작하고 실물과 파일 해시를 확인했다. 각 자산은 해당 사건 범주에만 허용한다. 두 이미지 모두 실제 Groq Vision 개별 검수를 통과했다. 개별 이미지 통과와 완성 표지/영상 통과는 별개다. 최종 3건 실행: https://github.com/betterbit-ai/today_econ/actions/runs/39047482786 (SHA 97ceae950c524afdfe1dc3cab639b10df4c7ac7d).

표본 3건은 전체 가용성·조회 증가의 증거가 아니다. 적합한 사진/전용 생성 자산이 없는 뉴스는 계속 건너뛰며, 반복 탈락 주제는 사건별 자산을 추가해 개선한다. 매 기사 자동 이미지 생성이나 새 유료 이미지 API는 추가하지 않았다. 새 예약 발행의 Instagram 결과와 Pro 사용량은 후속 운영 증거다. 이번 실제 테스트에서는 Instagram에 게시하지 않았다.

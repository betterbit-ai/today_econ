# 운영 복구 이후 콘텐츠 개선 착수 메모

상태: 준비 자료. 자동 활성화·새 ready 패키지·새 발행을 뜻하지 않는다. D0는 계정 읽기 접근과 정상 예약 발행이 확인된 후 정한다.

## 첫 화면 실험

- 실험 질문: 제목 아래 검증된 핵심 사실 한 줄을 보여주면 정시 24h 도달·시청 비율·저장/공유 발생률이 개선되는가?
- 같은 적합성 검사를 통과한 flash만 기사 ID 해시로 control/fact_line 배정한다. 같은 기사를 두 번 발행하지 않는다.
- 기존 claim과 원문 참조를 재사용한다. 영향·전망·새 숫자를 덧붙이지 않는다. 사실 32자·두 줄·최소 44px, 제목 2·3줄 조합을 실제 렌더로 확인한다.
- 넘치면 차단하고 자르거나 과도하게 축소하지 않는다. 기존 안전 영역과 6초, 음악·시각을 유지한다.
- 각 안의 정시 24h 10편과 분야별 충분한 표본 전에는 우열을 보류한다. unavailable은 0이 아니며 늦은 관측은 실험 비교에 넣지 않는다.
- 첫 화면 설정으로 즉시 복구 가능하게 하고 실험 ID·배정안·근거 참조를 새 analytics에 남긴다.

## Basic 재제작의 고정 ID

| 원본 ID | 새 버전 ID | 먼저 고칠 내용 |
|---|---|---|
| isa-tax | isa-tax-r2 | 모든 손실을 합친다는 표현을 세법상 인정 손실 범위로 제한한다. 한도·세율은 현재 공식 근거를 완전히 확인하지 못하면 제외한다. |
| etf-etn | etf-etn-r2 | 구조와 발행사 신용위험을 구분하고 두 상품 모두 원금 손실 가능성을 설명한다. 모든 ETF가 분산투자라는 일반화를 피한다. |
| fixed-variable-rate | fixed-variable-rate-r2 | 기준금리와 실제 대출금리를 구분하고 반영 시점·폭이 상품마다 다를 수 있음을 유지한다. |
| credit-score-rate | credit-score-rate-r2 | 같은 점수가 같은 금리를 보장하지 않으며 금리인하 요구가 승인과 같지 않음을 설명한다. 검증 안 된 심사요소 목록은 빼거나 추가 공식 근거를 확보한다. |

각 새 ID에 originalContentId를 연결한다. 원본 발행 기록·파일·해시는 덮어쓰지 않는다. 질문+짧은 답→정의→작동→주의→정리, 3/4/5/4/3초의 5장 19초 계약을 유지한다.

사전 조사에서 확보한 공식 출처는 아래와 같다. 실제 패키지 작성 시 원문과 발행 시점 유효성을 다시 대조하고 기관 두 곳 이상의 atomic claim 매핑을 완성한다. 링크가 있다는 이유로 checkedAt이나 ready를 먼저 찍지 않는다.

- ISA: [조세특례제한법 제91조의18](https://www.law.go.kr/LSW//lsSideInfoP.do?docCls=jo&joBrNo=18&joNo=0091&lsiSeq=284389&urlMode=lsScJoRltInfoR), [금융위원회 ISA 설명](https://www.fsc.go.kr/po020201/27339?curPage=&srchKey=ISA). 옛 FAQ는 개념 근거로만 사용하고 현재 숫자는 현행 법령·시행령으로 확인한다.
- ETF/ETN: [한국거래소 ETF 소개](https://open.krx.co.kr/contents/OPN/01/01030100/OPN01030100.jsp), [한국거래소 ETN 위험](https://open.krx.co.kr/contents/OPN/01/01030303/OPN01030303.jsp), [금융위원회 단일종목 레버리지 자료](https://www.fsc.go.kr/no010101/86973). 마지막 자료의 범위를 모든 ETF로 확대하지 않는다.
- 금리: [한국은행 기준금리 설명](https://www.bok.or.kr/portal/bbs/B0000217/view.do?listType=G&menuNo=200144&nttId=233448&pageIndex=4), [금융위원회 대출금리 구성](https://www.fsc.go.kr/no010101/79527).
- 신용: [한국은행 신용위험 개념](https://www.bok.or.kr/portal/bbs/B0000218/view.do?menuNo=200&nttId=10017545&pageIndex=12&searchOptn2=), [금융위원회 신용평가 개선](https://www.fsc.go.kr/no010101/73473), [금리인하요구 제도](https://www.fsc.go.kr/no010101/79410). 옛 등급제를 현재 점수 계산 규칙으로 소개하지 않는다.

패키지는 자연스러운 한국어, 카드 5장 시각 검수, bright 음원 실제 청취, ffprobe 규격, 모든 파일 해시 검증 뒤에만 ready로 표시한다. 예약 실행은 완성 패키지를 검증·발행만 한다.

## 프로필 적용 확인

선정 기준·대표 기초·주간 선별 3개 PNG는 `content/profile-funnel/`에 준비돼 있다. 주간 선별의 실제 내용과 날짜는 적용 시점에 다시 확인한다. 게시물 업로드·상단 고정·하이라이트 적용은 계정 UI 작업으로 별도 증거를 남긴다. 코드에 이미지가 있다는 것만으로 계정 적용 완료로 체크하지 않는다.

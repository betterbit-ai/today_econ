## 원인 1: 후보·카테고리·프레임 품질 이탈

최근 원장이 직접 보여 주는 대표 사례는 다음과 같다.

- `고독사 위험군 / 분석 보고`: 고독사 기사를 `건보료 개편`,
  `insurance_premium`으로 잘못 잠그고 자동차보험 이미지를 검색했다.
- `스마일게이트 / IPO 예정`: 이혼 재산분할 기사에서 회사 IPO를 주요 사건으로
  바꿨다.
- `후티 해협 장악 / 이란 지휘`: 군사·외교 기사가 Economy로 발행됐다.
- `중국 자매 / 불륜 폭로`: 개인 폭로 기사를 `주거 정책`으로 프레이밍하고
  시장 이미지를 붙였다.
- `한국 음식점 / 실내 금연 시행`, `복권 1등 당첨 / 대출금 상환`: Economy의
  지속 가능한 독자 효용보다 생활 호기심에 가깝다.
- `이소은 뮤지컬 / 건전지 엄마`: 연예인 근황이 Issue로 발행됐다.
- `연준 금리 인상 / 확정`: Economy 사건이 Issue로 들어갔고, 원문상 임박한
  변수를 확정으로 강화했다.

`분석 보고`, `비판`, `보도`, `확정`처럼 두 줄만 보고 사건을 이해하기 어려운
표지도 반복됐다. 최근 높은 성과 예외는 `국민의힘 / 비판` 2,449회,
`장동혁 / 호르무즈 파병 경고` 2,100회처럼 전국 정치·안보 관심이 큰 사건이었다.
예외 한두 편은 광범위한 저품질 후보를 정당화하지 않는다.

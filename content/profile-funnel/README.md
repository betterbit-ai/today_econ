# DIEM 프로필 전환 패키지

## 고정 게시물 순서

1. `01-selection-criteria.svg` — DIEM이 뉴스를 고르는 기준
2. `02-basic-start.svg` — DIEM Basic 첫 4개 학습 순서
3. `03-weekly-top3.svg` — 이번 주 꼭 볼 뉴스 3개

주간 Top 3는 조회수가 아니라 저장·공유와 생활 관련성을 우선해 매주 문구를
교체한다. SVG는 1080×1350 원본이며 Instagram 업로드 전 PNG로 내보낸다.

## 하이라이트

- 오늘경제: 금리·물가·주거·일자리처럼 돈과 생활이 바뀌는 뉴스
- 오늘시사: 정책·안전·공공서비스처럼 알아야 할 변화
- 경제기초: DIEM Basic 첫 4편부터 이어지는 초보자 학습 동선
- DIEM 소개: 선정 원칙, 정정 원칙, 이미지·출처 정책

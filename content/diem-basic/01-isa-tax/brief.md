# 01. ISA 세금 줄이는 방식

- 학습 질문: ISA는 어떤 세금을 줄여주는 계좌인가?
- 한 문장 목표: “절세 계좌”라는 광고 문구 대신 손익통산 → 비과세 → 초과분
  분리과세 순서를 이해하게 한다.
- 핵심 오해 방지: 모든 소득이 무제한 비과세되는 계좌가 아니다.
- 근거 우선순위: 현행 법령을 기준으로 하고 금융위원회 설명으로 제도 취지를
  교차검증했다.
- 영상 구성: 질문 → 손익통산 흐름 → 유형별 비과세 한도 → 초과분 9.9%
  분리과세 → 최신 법령 확인 순서의 5장 수업이다.
- 디자인: 웜 아이보리 노트 위에 흐름도·비교표·산식을 배치해 뉴스 표지와
  구분하고 사람·지폐·기사 사진은 사용하지 않는다.
- 갱신: 세법 수치가 포함되므로 첫 발행 전과 2026-09-30 이전에 다시 확인한다.

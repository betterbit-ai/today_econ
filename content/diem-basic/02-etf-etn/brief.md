# 02. ETF·ETN 핵심 차이

- 학습 질문: 이름이 비슷한 ETF와 ETN은 무엇이 다른가?
- 한 문장 목표: 둘 다 거래소에서 지수를 추종하지만 하나는 펀드 지분이고,
  다른 하나는 증권사가 발행한 증권이라는 차이를 기억하게 한다.
- 핵심 오해 방지: 거래 방법이 비슷하다고 법적 구조와 위험까지 같은 것은 아니다.
- 근거 우선순위: 한국거래소의 상품 정의를 중심으로 금융감독원의 위험 안내를
  교차검증했다.
- 영상 구성: 공통 거래 방식 → ETF·ETN의 법적 구조 → ETN 발행사 신용위험
  → “거래법은 비슷해도 구조는 다르다” 순서의 5장 수업이다.
- 디자인: 웜 아이보리 노트 위의 흐름도·양쪽 비교표·위험 체크리스트로
  설명하며 사람 얼굴, 기업 로고와 웹 사진을 쓰지 않는다.

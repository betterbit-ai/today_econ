# 03. 고정·변동 금리 차이

- 학습 질문: 한국은행이 금리를 바꾸면 내 대출금리도 바로 바뀌는가?
- 한 문장 목표: 고정 기간, 변동 주기, 기준지표와 재산정일을 분리해서 본다.
- 핵심 오해 방지: 기준금리 뉴스와 개인 대출금리는 같은 날 같은 폭으로
  움직이지 않는다.
- 근거 우선순위: 한국은행의 정의와 파급경로, 은행연합회의 COFIX 공시,
  금융위원회의 대출금리 설명을 교차검증했다.
- 영상 구성: 고정·변동의 정의 → 대출금리 산식 → 기준금리 반영 시차 → 계약서
  확인 항목 순서의 5장 수업이다.
- 디자인: 웜 아이보리 노트 위의 비교표·4항 산식·재산정 타임라인으로
  설명하며 자물쇠 사진이나 은행 인물 사진은 사용하지 않는다.

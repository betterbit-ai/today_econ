# DIEM 추가 콘텐츠·팔로우 전환 기획안

> 상태: 제안안 — 구현 전 사용자 확인 필요
> 작성일: 2026-08-05
> 기준: `spec/mission.md`, 현재 DIEM 릴스 형식, 최근 10만 조회 릴스 성과

## 1. 목표

핫뉴스 릴스의 도달을 유지하면서, 프로필을 방문한 사람이 “다음에도 볼
이유”를 발견하도록 저장형 콘텐츠와 반복 시리즈를 더한다. 조회수 자체보다
도달 계정 대비 프로필 방문·팔로우·저장 전환을 개선한다.

## 2. 지키는 원칙

1. 현재 단일 표지 릴스의 제목·비주얼 형식은 유지한다.
2. `정확히 3문장`은 제작 규칙이며 표지나 소개의 마케팅 문구로 쓰지 않는다.
3. 기사에 없는 전망·투자 조언을 만들지 않는다.
4. OBMC의 성장 구조는 참고하되 이름·문구·디자인은 복제하지 않는다.
5. 추가 콘텐츠가 핫뉴스 자동 발행의 신선도와 안정성을 해치지 않게 별도
   시리즈와 성과 기록으로 운영한다.

## 3. 현재 진단

- 10만 조회 릴스는 발견성과 공유성은 증명했지만 도달 54,904계정 중
  팔로우 11명으로, 한 건의 화제성이 계정 구독 이유로 이어지지 않았다.
- DIEM은 게시물 87개로, 1,000개 이상 콘텐츠가 쌓인 롤모델 계정보다
  프로필 방문자가 연속 탐색할 저장형 콘텐츠가 적다.
- 현재 피드는 시의성 높은 뉴스가 중심이어서 기사 유효기간이 지나면 다시
  찾아볼 이유가 약하다.
- 해결책은 표지에 팔로우 CTA를 반복하는 것이 아니라, 프로필 안에
  입문·저장·연속 소비 경로를 만드는 것이다.

## 4. 콘텐츠 포트폴리오 제안

### A. 핫뉴스 브리핑 — 전체 피드의 약 70%

- 현재 Economy·Issue 자동 발행을 유지한다.
- 한 사건, 한 숫자, 한 변화가 명확한 뉴스를 우선한다.
- 급상승 릴스는 24시간 안에 Story 후속 설명이나 투표로 연결한다.

### B. `DIEM 기초` — 약 20%, 주 1회 시험 운영

재테크 초보자가 저장할 수 있는 하나의 경제 개념을 실제 최근 뉴스와
연결한다.

예시:

- 기준금리가 내 대출금리에 반영되는 순서
- ETF와 ETN의 가장 중요한 차이
- 코스피가 올라도 내 종목은 떨어지는 이유
- IPO 공모가·시초가·상장일 차이

형식 원칙:

- 표지는 질문 또는 핵심 차이 한 가지
- 본문은 정의 → 최근 사례 → 주의할 오해 순서
- 특정 상품 추천이나 수익 약속 금지
- 출처와 기준일을 기록하고 시간이 지나면 재검증

### C. `이번 주 DIEM` — 약 10%, 주 1회 시험 운영

일주일 동안 발행한 경제·시사 중 다시 볼 가치가 큰 3건을 묶는다.

- 단순 조회수 순위가 아니라 저장·공유·독자 생활 연관성으로 선정
- 같은 사건의 반복 요약은 제외
- 각 뉴스가 이후 어떻게 바뀌었는지 확인된 사실만 한 줄로 갱신
- 초기에는 Story 묶음과 하이라이트로 운영하고, 성과가 확인되면 별도
  피드 형식을 검토

## 5. 프로필 전환 구조

### 고정 게시물 3개

1. `DIEM은 어떤 뉴스를 고르나요?`
2. `재테크 초보가 먼저 볼 DIEM 기초 5개`
3. `이번 주 가장 중요했던 경제·시사`

### Story 하이라이트

- `오늘경제`
- `오늘시사`
- `경제기초`
- `DIEM 소개`

소개 문구는 현재처럼 독자 효용을 말한다.

```text
돈과 세상을 이해하는 가장 빠른 방법
오늘의 경제·시사를 쉽고 정확하게
협업/문의: DM
```

## 6. 이미지 운영 원칙

추가 콘텐츠와 핫뉴스 모두 다음 순서를 공유한다.

1. 사건과 직접 연결된 장소·기관·제품·문서·사물
2. 식별 가능한 사람이 없는 개념 사진
3. 최근 사용하지 않은 검수된 무인물 분야 이미지
4. 모든 맥락 사진이 실패했을 때만 동일성이 검증된 핵심 인물 사진
5. DIEM 주제별 타이포그래피 표지

자동 스톡 사진에 식별 가능한 사람이 등장하면 기사와 닮아 보이더라도
탈락시킨다. 인물 사진을 쓸 때만 이름·출처·라이선스·사진 설명의 동일성
근거를 기록한다. 대통령·장관·기업인 기사도 얼굴보다 관련 기관, 브리핑
장소, 법안, 제품, 시장 화면처럼 사건을 설명하는 배경을 우선한다.

## 7. 4주 시험 운영안

### 준비 주간

- 고정 게시물 3개와 하이라이트 구조 설계
- 기존 게시물에서 `DIEM 기초` 후보 5개 선정
- Insights 기록에 도달·프로필 활동·팔로우·저장·공유 항목 확인

### 1~4주차

- 기존 핫뉴스 자동 발행 유지
- `DIEM 기초` 주 1건
- `이번 주 DIEM` Story 주 1회
- 급상승 Reel 후속 Story는 조건 충족 때만 추가

### 종료 평가

최소 4주 또는 추가 콘텐츠 각 4건 이상이 쌓인 뒤 다음을 비교한다.

- 도달 계정 대비 팔로우
- 도달 계정 대비 저장
- 프로필 활동을 제공하는 경우 도달 대비 프로필 방문
- 신규 팔로워가 처음 본 콘텐츠 유형
- 핫뉴스만 본 집단과 저장형 콘텐츠를 본 집단의 전환 차이

표본이 작을 때는 한 건의 바이럴 결과로 전략을 확정하지 않는다.

## 8. 구현 범위 제안

### 1차 — 운영 기반

- 추가 콘텐츠 타입과 성과를 GitHub JSON에 기록할 스키마
- 고정 게시물·하이라이트용 원고 초안 생성 명령
- 인물 없는 맥락 이미지 우선순위와 사람 검출 실패-폐쇄 가드

### 2차 — 반자동 제작

- 지난 발행 기록에서 `DIEM 기초`와 주간 정리 후보 추천
- 운영자 승인 후에만 추가 콘텐츠 생성
- 콘텐츠 유형별 Insights 비교 리포트

### 현재 제외

- 추가 콘텐츠의 완전 자동 Instagram 발행
- 유료 이미지·분석 서비스
- 개인별 투자 추천
- 조회수를 위한 정치·연예 이슈 비중 확대

## 9. 완료 기준

- 사용자가 추가 콘텐츠 2종, 빈도와 고정 게시물 구성을 승인한다.
- 일반 스톡 인물 사진이 자동 표지에 들어가지 않는 검증 방식이 확정된다.
- 추가 콘텐츠가 기존 핫뉴스 원장과 구분되어 성과를 비교할 수 있다.
- 4주 시험 종료 후 유지·수정·중단을 결정할 지표가 누락 없이 기록된다.

## 10. 롤백

추가 콘텐츠 제작 부담이 크거나 전환 개선이 없으면 추가 시리즈만 중단하고
핫뉴스 Economy·Issue 자동 파이프라인은 그대로 유지한다. 기존 게시물과
발행 원장 스키마는 삭제하지 않고 유형을 `inactive`로 표시한다.

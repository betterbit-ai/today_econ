# Mission

## One-line definition

경제와 시사 분야의 현재 인기 뉴스가 충분히 중요하고 신선할 때만 선별해,
경제뉴스를 챙길 시간이 부족한 20~30대 직장인과 사회초년생 재테크
초보자에게 짧고 이해하기 쉬운 릴스로 전달하는 데일리 경제 매거진이다.

## Who it serves

경제와 시사 흐름은 알고 싶지만 원문 기사를 매일 찾아 읽을 시간과
배경지식이 부족한 20~30대 직장인 및 사회초년생 재테크 초보자를
핵심 독자로 삼는다.

## Why it exists

독자가 경제·시사 원문을 모두 읽지 않아도 1분 안에 그날의 핵심 사실과
맥락을 정확하게 파악하도록 돕는다. 기사에 명시된 전망이나 의미는
선별해 전달하되, 근거가 없을 때는 억지 인사이트를 만들지 않고 정확한
요약에 집중한다.

## Core principles

1. 주제 선정과 타이틀은 대중의 관심과 클릭 동기를 우선하되, 사실을
   왜곡하거나 낚시성 표현을 사용하지 않는다.
2. 본문은 기사에 근거한 정확성을 지키며, 정보의 양보다 정확히 3문장,
   문장당 최대 약 120자 안에서 빠르게 이해되는 간결함을 우선한다.
3. 별도 데이터베이스와 유료 인프라보다 GitHub 기록을 활용한 단순하고
   추적 가능한 운영을 우선한다.
4. 정해진 시각을 채우기 위한 발행보다 뉴스가 주목받는 시점의 신속성과
   품질을 우선하며, 같은 사건을 반복 발행하지 않는다.

## Explicit non-goals

- 개인별 투자 추천이나 매수·매도 조언을 제공하지 않는다.
- 기사에 없는 전망이나 인사이트를 억지로 생성하지 않는다.
- 모든 속보를 빠짐없이 다루는 종합 실시간 뉴스 채널을 목표로 하지
  않는다. 공개 인기·신선도 기준을 통과한 뉴스만 제한적으로 발행한다.
- OBMC의 운영 전략은 참고하지만 이름, 로고, 문구, 디자인을 그대로
  복제하지 않는다.
- 현 단계에서는 별도 데이터베이스와 상시 유료 인프라를 도입하지
  않는다.

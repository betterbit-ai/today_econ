# 최종 표지 해시는 같은 폴백 원본의 재사용을 숨길 수 있다

## Situation

국회 법안 기사와 옥상 폭염 노동 기사에 사흘 사이 같은 Issue SVG 배경이
발행됐다. 기존 7일 중복 가드는 공급자 ID·URL·다운로드 SHA를 비교했지만,
타이포그래피 폴백에는 ID가 없었다. 대신 제목과 날짜까지 합성한 최종 표지
PNG의 SHA가 `localSha256`으로 기록되어 두 결과가 서로 다른 이미지처럼
보였다.

동시에 한국어 법률 문구와 숫자 중심 검색어가 글로벌 스톡 API에 전달됐고,
국내 기사라는 이유만으로 장소를 주장하지 않는 개념 사진에도 한국 위치
메타데이터가 요구됐다. 의미 있는 후보가 모두 제거되면서 고정 폴백 사용이
반복됐다.

## What we learned

- 합성 산출물 해시는 원본 배경 자산의 정체성을 대신할 수 없다. 재사용을
  막으려면 웹 사진과 생성·폴백 아트 각각에 합성 전 안정 식별자가 필요하다.
- 이미지 검색은 기사에 나온 모든 명사를 동등하게 취급하면 안 된다. `아파트
  옥상 폭염 작업`에서 시각 사건은 부동산이 아니라 노동·폭염이다.
- 지리 가드는 사진이 특정 기관·장소라고 주장할 때 적용해야 한다. 법률 문서,
  의사봉, 작업 안전 같은 개념 사진에 기사 국가명까지 요구하면 안전한 후보를
  불필요하게 버린다.

## Next time

- 폴백 아트는 `visualFingerprint`와 주제·변형 번호를 원장에 기록하고 웹
  사진과 같은 최근 7일 중복 집합에 넣는다.
- 검색어 회귀 테스트에는 핵심 사건과 충돌하는 부수 키워드를 반드시 포함한다.
- 장소 사진과 개념 사진의 지리 요구를 분리하고, 외국 기관 사진 차단 테스트는
  계속 유지한다.

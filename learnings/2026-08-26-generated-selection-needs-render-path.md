# 생성 자산 선택 기록만으로는 실제 표지 사용을 보장하지 않는다

## Situation

원장에는 `diem-generated` 자산이 선택됐지만 publisher가 web 다운로드 결과의
`localPath`만 표지 렌더러로 전달했다. 생성 자산은 선택 단계에서 이미 로컬
경로를 가지고 있어도 렌더러 입력에서는 빈 값이 되어 기본 아트로 보일 수 있었다.

## What we learned

이미지 품질은 선택 결과와 렌더 입력을 함께 검증해야 한다. 원장의 `kind`만 보고
생성 이미지가 실제 픽셀에 들어갔다고 판단하면 안 된다.

## Next time

생성 자산 회귀 테스트는 `image.kind`뿐 아니라 렌더러에 전달된 실제 파일 경로와
파일 존재까지 검사한다. 웹 다운로드 실패·중복 해시·자산 소진 경로도 각각
타이포그래피로 내려가지 않는지 고정한다.

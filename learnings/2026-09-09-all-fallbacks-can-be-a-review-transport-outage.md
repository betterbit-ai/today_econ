# 폴백 100%는 이미지 공급 부족보다 검수 전송 장애일 수 있다

## Situation

최근 8일간 모든 Reel이 생성 또는 타이포그래피 폴백으로 나갔다. Pexels,
Unsplash, Wikimedia가 적합 후보를 반환한 기사도 있었지만 Vision JSON 400과
이미지 URL 403이 반복됐고, 선택기는 첫 장애에서 검색 루프를 중단했다.

## What we learned

웹 이미지 후보 수, 결정적 메타데이터 적합성, Vision 기술 성공, Vision 문맥
승인을 별도 단계로 기록해야 한다. 기술 실패를 문맥 거부와 같은 것으로 다루면
안전한 fail-closed 정책이 장기간의 폴백 강제로 변한다. 생성 폴백 분류도 기사
전체가 아니라 이미 잠긴 주요 사건만 사용해야 `부동산 중개인→주거`, `도서관
노동자→직장` 같은 누수를 막을 수 있다.

## Next time

폴백률이 갑자기 상승하면 공급원 추가보다 먼저 Vision 오류 분포와 루프 중단
지점을 확인한다. JSON 형식·원격 URL 장애는 제한적으로 복구하고, 실제 문맥
거부는 다음 검색 의도로 이동한 뒤 생성 자산으로 닫는다.

# 로컬 개선·계정 상태·발행 성공은 각각 증거를 확인한다

10월 13일 성과 진단에서 로컬의 v3 분류·Vision·측정 보호가 검증됐지만
원격 main은 여전히 v2였고, 실제 원장에는 폐기되거나 접근 불가한 모델 오류와
explain 발행이 이어졌다. 성과 평가 전에 main SHA·Action SHA·원장 스키마·
실제 Reel을 연결해야 한다. 로컬 테스트 통과와 운영 적용 완료를 구분한다.

같은 날 Instagram API는 User access is restricted를 반환했지만 실제 웹
계정 상태는 도달 제한 없음·비팔로워 추천 가능·모든 기능 사용 가능이었다.
HTTP 상태와 문자열만으로 추천 제한이나 섀도밴을 확정하지 않는다.
원본 error code·subcode·계정 권한과 발행 결과를 별도 확인한다.

제목에 원문의 숫자가 들어 있어도 의미가 보존된 것은 아니다.
3년 9개월에서 3년이 빠지거나, 미신청 가구 중 청년 비중을 청년 미신청률로
바꾸는 오류는 숫자 존재 검사로 잡히지 않는다. 기간·분모·단위·조건을
source span과 함께 검수하고 실제 사례를 회귀 fixture로 남긴다.

새 전략을 판단할 때 과거 영상 길이를 기본 6초로 간주하거나 Basic을
일반 뉴스에 섞지 않는다. 동일 관찰창·콘텐츠 유형·실제 길이를 분리한다.
누적 전체 팔로워 변화와 최근 14일 변화도 다른 구간이다.
